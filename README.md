# Mock Rental Car Website

A multi-page, responsive web application designed to simulate a real-world rental car booking experience. Built using HTML, CSS, and JavaScript — with live weather integration and embedded maps — this project showcases practical web design and development skills.

---

## What It Is

This is a fully functional mock rental car website. It includes:

- **Homepage** with a welcome message and live weather widget  
- **Rentals page** dynamically showing available vehicles  
- **Reservation page** with a booking form  
- **Contact page** featuring embedded Google Maps  

Users can browse rental cars, check pricing, view pickup locations, and get real-time weather updates using the OpenWeatherMap API. All data is locally simulated using JSON.

---

## Why I Built It

I wanted to practice integrating multiple front-end skills in a realistic project scenario. A car rental site offered a perfect opportunity to:

- Build a responsive, real-world interface  
- Work with APIs and asynchronous JavaScript  
- Improve DOM manipulation and dynamic content generation  

Adding real-time data (weather) and dynamic car listings made the site feel more alive and practical.

---

## How I Built It

Technologies and techniques used:

- **HTML** for semantic structure  
- **CSS** for layout and responsiveness  
- **JavaScript** for interactivity and DOM manipulation  
- **Local JSON** to simulate vehicle data  
- **OpenWeatherMap API** for real-time weather  
- **Google Maps Embed** for displaying rental locations  

### Page Overview:

- **Home**: Intro, banner, weather widget  
- **Rentals**: Dynamic listings pulled from JSON  
- **Reservations**: Form with date/time/vehicle fields  
- **Contact**: Map + business contact info  

---

## Challenges I Faced

- **Asynchronous JavaScript**: Fetching API data and error handling took trial and error  
- **DOM Manipulation**: Loading car cards from JSON dynamically  
- **Mobile Responsiveness**: Making layouts work well on phones  
- **Form Validation**: Added HTML validation; want more logic-based checks in the future

## What I'd Do Differently

If I iterate on this again, I’d:

1. Add filtering/sorting on the rentals page (e.g., by car size or price)  
2. Replace static JSON with a backend (like Firebase or Express.js)  
3. Improve the weather widget to reflect user-selected locations  
4. Enhance accessibility (ARIA, keyboard navigation, etc.)
